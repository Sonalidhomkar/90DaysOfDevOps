# Day 22 – Introduction to Git

## What I Learned

Today, I learned the basics of Git and version control.

### 1. Difference Between git add and git commit
`git add` stages changes, while `git commit` saves the staged changes in the local repository.

### 2. What Is the Staging Area?
The staging area allows us to select which changes should be included in the next commit.

### 3. What Does git log Show?
The `git log` command displays the commit history, including commit IDs, authors, dates, and messages.

### 4. What Is the .git Directory?
The `.git` directory stores repository information and version history. Deleting it removes the local repository metadata.

### 5. Working Directory, Staging Area, and Repository
- Working Directory: Where we create and edit files.
- Staging Area: Where we prepare changes for a commit.
- Repository: Where Git stores committed changes and history.

## Conclusion

This practice helped me understand Git fundamentals, repository initialization, staging, committing, and viewing commit history.
