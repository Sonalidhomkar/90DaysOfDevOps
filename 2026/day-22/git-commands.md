# Git Commands Reference

## 1. Check Git Version

```bash
git --version
```
Checks the installed Git version.

## 2. Initialize Repository

```bash
git init
```
Creates a new local Git repository.

## 3. Check Repository Status

```bash
git status
```
Shows the current status of files.

## 4. Stage Changes

```bash
git add .
```
Stages changes for the next commit.

## 5. Commit Changes

```bash
git commit -m "Initial commit"
```
Saves staged changes in the local repository.

## 6. View Commit History

```bash
git log --oneline
```
Displays commit history in a compact format.

## 7. View Changes

```bash
git diff
```
Shows changes that have not yet been staged.

## 8. View Hidden Files

```bash
ls -a
```
Lists all files, including hidden files such as `.git`.
