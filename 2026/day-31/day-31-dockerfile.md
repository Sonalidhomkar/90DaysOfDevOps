# Day 31 – Dockerfile: Build Your Own Images 🐳

## Objective
Learn how to create custom Docker images using Dockerfiles and understand the Docker image build process.

## Practical Tasks Completed

### 1. First Dockerfile
- Created a custom Ubuntu image.
- Installed curl using RUN.
- Executed a command using CMD.
- Built and ran `my-ubuntu:v1`.

### 2. Dockerfile Instructions
Practiced:
- FROM
- RUN
- COPY
- WORKDIR
- EXPOSE
- CMD

### 3. CMD vs ENTRYPOINT
- Understood the difference between CMD and ENTRYPOINT.
- Tested command overriding and runtime arguments.

### 4. Nginx Static Website
- Created a custom HTML website.
- Built a custom Nginx image.
- Ran the website inside a Docker container.
- Accessed it through localhost.

### 5. .dockerignore
Practiced excluding unnecessary files:
- node_modules
- .git
- *.md
- .env

### 6. Docker Build Cache
- Rebuilt Docker images.
- Observed cached layers.
- Modified HTML content and tested the build again.

## Key Learnings
- Creating custom Docker images.
- Writing and understanding Dockerfiles.
- Running containers.
- Hosting static websites using Nginx.
- Using .dockerignore.
- Understanding Docker build cache.
